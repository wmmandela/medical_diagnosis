UNCERTAINTY MATHEMATICS

Certainty Factors (CF) & Multiplicative Logic

Certainty Input Values

  • CF = 1.0 (Yes / Confirmed): Symptom is definitely present. Multiplies running CF by 1.0.
  • CF = 0.5 (Maybe / Uncertain): Symptom is uncertain. Multiplies running CF by 0.5.
  • CF = 0.0 (No / Absent): Symptom is absent. Multiplies running CF by 0.0 (short-circuits rule).
  • Prior Rule Confidence: Each rule starts with expert base confidence (e.g. Malaria: 0.90).

Multiplication Formula

  • Chain Multiplication: CF_final = CF_rule * CF_symptom1 * CF_symptom2 * ... * CF_symptomN.
  • Strict Monotonicity: Each additional uncertain step can only maintain or decrease total confidence.
  • Candidate Ranking: Surviving candidates are ranked by final combined CF to pick the top winner.

EXPLAINABLE AI

Explanation Facilities (WHY & HOW)

WHY Explanation Facility

  • User Trigger: Activated when user types 'why' during follow-up questioning.
  • Function: explain_why(symptom_name, hypothesis_disease)
  • Explanation: Tells the user which disease hypothesis is currently being tested and why that symptom matters.

HOW Explanation Facility

  • Auto Trigger: Activated automatically once a diagnosis is concluded.
  • Function: explain_how(diagnosed_disease, final_cf, rule_cf)
  • Breakdown: Prints base rule confidence and individual confirmed symptom CF values.

ENGINE LOGIC

Backward Chaining Inference Algorithm

1. Chief Complaint Intake

  • User enters chief complaint symptom.
  • Chief complaint asserted with CF = 1.0.
  • System matches candidate disease rules.

2. Dynamic Follow-Up

  • Loops through remaining required symptoms.
  • Prompts user for 'yes', 'no', 'maybe', 'why'.
  • Short-circuits early if symptom CF = 0.0.

3. Ranking & Output

  • Multiplies CF values along reasoning path.
  • Selects hypothesis with highest surviving CF.
  • Displays winning diagnosis & HOW trace.

RESEARCH INSIGHTS

Key Notebook Findings & Behavior

Key System Behaviors

  • Sequential Evaluation: Diseases evaluated in dictionary insertion order (Malaria -> Typhoid -> Influenza -> Common Cold).
  • Short-Circuiting: A single 'no' (CF = 0.0) disqualifies a hypothesis immediately, saving questions.
  • Global Winning Score: Final diagnosis is the surviving candidate with the HIGHEST combined CF.

Future Work Improvements

  • Multiple Complaints: Support multiple chief complaints at startup.
  • Continuous Sliders: Allow 0-100% granular confidence input sliders.
  • Session Storage: Persist patient fact base across multiple consultations.
