Project Presentation

AegisMed AI Medical Expert System

A comprehensive, explainable AI-powered Hospital Medical Diagnosis Expert System leveraging Kanren relational logic, Spring Boot backend, and Flutter / Web UI.

Kanren Logic Engine

Python relational logic programming using Relation, facts, var, run, lall, conde, and eq.

Spring Boot REST API

Java backend handling authentication, patient history, session management, and PDF report export.

Dynamic Knowledge Base

30+ Diseases, symptom taxonomy, recommendations, lab investigations, and contraindications in JSON.

System Architecture & Flow

Decoupled multi-tier microservice architecture designed for maintainability and scalability.

Frontend Tier

Flutter cross-platform app codebase & live interactive web dashboard with glassmorphism UI.

Backend Tier

Spring Boot REST controllers, JPA/Hibernate persistence, and H2/PostgreSQL database support.

Inference Tier

FastAPI/Python Kanren service evaluating reported symptoms against declarative relations.

Kanren Relational Inference Code

Declarative logic rules mapped directly in Python Kanren syntax:

from kanren import Relation, facts, var, run, lall, conde, eq

disease_symptom = Relation("disease_symptom")
facts(disease_symptom, ("malaria", "fever"), ("malaria", "chills"), ("malaria", "headache"))

d = var()
# Query Kanren Engine: Find all diseases d matching fever and chills
results = run(0, d, lall(disease_symptom(d, "fever"), disease_symptom(d, "chills")))
